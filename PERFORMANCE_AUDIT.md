# Valheim Legends - Auditoria Completa de Performance de Runtime

Este documento cataloga todos os problemas de desempenho identificados no código C# do mod **Valheim Legends** (commit base `46914bbc7f68f862bb6514b0f333abcdc19cbd0f`), visando o ambiente **Valheim 1.0.12 (Unity 6 / Deep North)**.
Este documento cataloga exaustivamente todos os problemas de desempenho identificados e corrigidos no código C# do mod **Valheim Legends** (commit base `46914bbc7f68f862bb6514b0f333abcdc19cbd0f`), visando o ambiente **Valheim 1.0.12 (Unity 6 / Deep North)** e runtime `netstandard2.1`.

---

## Escala de Prioridades
- **P0**: Por frame ou por hit, alto consumo de CPU ou de Garbage Collection. Hotspot crítico.
- **P1**: Recorrente e relevante (combate contínuo, buffs frequentes, watchdogs visuais).
- **P2**: Ocasional (invocação de habilidades pontuais, transições, buscas globais lentas).
- **P3**: Startup, carregamento de configuração ou inicialização única.
